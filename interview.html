INTERVIEW SESSION

アルゴリズムの内側と、私たちのこれから

私たちは毎日、アルゴリズムが選んだタイムラインの中で生きています。
そのしくみを「つくる側」と「見続けてきた側」に話を聞き、@IronYとしてインタビューセッションを行いました。
まずは、インタビューをもとに制作した動画で、その空気を一緒に体験してください。

※ このページでは、動画でインタビューの感覚を味わってもらったあと、
実際のセッション内容の全文と、そこから生まれた私たち自身の問い・答えを順番にたどっていきます。

STEP 1

まずは動画で：インタビューの「温度」を感じる

note・金谷武明さんへのインタビューをもとにしたセッション動画です。
声のトーンや間合い、その場の空気感ごと感じてもらえるように構成しました。

  • プラットフォームがアルゴリズムに込めている「意図」
  • SNSが生み出す「出会い」と「しんどさ」の両面
  • ユーザー・企業・社会、それぞれの責任と役割

※ 通信量が大きくなる場合があります。Wi-Fi環境での視聴をおすすめします。

動画を見られない方へ：内容の概要

・アルゴリズムを「つくる側」「見続けてきた側」の声を交えたセッション動画です。
・便利さとしんどさ、どちらも生まれてしまう構造について話しています。
・最後に「私たちはどうSNSと付き合うか？」という問いを投げかけています。

STEP 2

実際のセッション：アルゴリズムとSNSの内側へ

ここからは、動画のもとになったインタビューセッションを、会話形式で再構成したものを掲載します。
一部、読みやすさのために言い回しや順序を編集していますが、内容は実際の発言に基づいています。 ※ 話者名は「聞き手」「note 今さん」「金谷さん」として表記しています。

3-1. noteに聞く「創作を支えるアルゴリズム」

クリエイターのためのプラットフォームを名乗る note は、「どんな世界を実現したいのか」をどうアルゴリズムに落とし込んでいるのか。
サービスの理念から、ランキングや広告を置かない理由、レコメンドが生む出会いとリスクまでうかがいました。

聞き手

まずは、日々の利用や記事を通じて note を知ってはいるのですが、改めて「どんなサービスを運営していて、どんな理念で動いているのか」を教えていただけますか。

note 今さん

私たちは「note.com」という CGM（Consumer Generated Media）、つまりユーザーがコンテンツを作って発信するタイプのメディアプラットフォームを運営しています。 中核になっているのが「note」というサービスで、今はこの note が事業としてもっとも大きな領域ですね。

聞き手

ミッションとして掲げられている「だれもが創作をはじめ、続けられるようにする」という言葉が印象的でした。 このミッションは、アルゴリズムの設計にどう関わっているのでしょうか。

note 今さん

プラットフォーム側から見ると、C to C のメディアなので「読みたい人に、読みたいコンテンツが届く」ことがものすごく大事なんです。 そのために、閲覧履歴やフォローしているクリエイター、近そうなジャンルなどを組み合わせて、 「読む可能性が高いであろうコンテンツ」をアルゴリズムと露出面のデザインでおすすめする、というイメージですね。

topic
ランキングも広告も置かない、その理由
聞き手

いま、SNSやプラットフォームはたくさんありますが、その中で note が特に大事にしている「差別化ポイント」はどこですか。

note 今さん

「クリエイターにとってストレスが少ない場所であること」はかなり意識しています。 クリエイター向けをうたうサービスは多いのですが、実際にはランキングがあったり、数字で煽られたり、広告がたくさん出ていたりしますよね。 そうすると、評価や数字に疲れてしまうクリエイターも多い。

note では、あえてランキングを置かない、サイト内のディスプレイ広告を載せない、といった設計にしています。 ビジネス的には異例かもしれませんが、「余計なプレッシャーを減らして、淡々と創作を続けられる場所」にしたいという意図が大きいです。

聞き手

実際に僕たちも note で記事を書いてみたのですが、「数字で煽られない」空気はすごく感じました。 「クリエイターに寄り添う」という言葉が、具体的な設計に落ちているのが分かります。

topic
レコメンドが生む「出会い」と、その裏側
聞き手

レコメンド機能についても伺いたいです。 アルゴリズムが、クリエイターと読者の新しい「出会い」を生んだと感じる場面はありますか。

note 今さん

note には本当にいろいろなジャンルの作品があります。 何もしないと、読者からすると「どこを見ればいいか分からない場所」になってしまうんです。

そこで、閲覧履歴やフォロー関係をもとに興味領域が近いものを出したり、 すでにファンになりつつあるクリエイターの新しい記事をきちんと届けたり、といったロジックを複数組み合わせています。 そうやって、まだ出会っていない作品との接点を増やしていこうとしているイメージですね。

聞き手

創作のモチベーションという意味では、アルゴリズムはどう貢献していると感じますか。

note 今さん

一番大きいのは「反応」です。 「スキ」がついた、PV が増えた、フォロワーが増えた、売上が上がった……こうした変化は、やはり多くのクリエイターにとって重要なモチベーションになります。

だからこそ、そうした反応が起こりそうな読者にコンテンツを届ける、つまりターゲティングの精度を高めていくことが、 アルゴリズム側でやっていることの中核だと思っています。

topic
「怒り」を煽らないために、アルゴリズムより大事にしているもの
聞き手

一方で、レコメンドが怒りや不安といった感情を増幅させるという指摘も増えています。 note では、そういった意図しない偏りを防ぐために、どんな工夫をされていますか。

note 今さん

まず、危険なコンテンツや違法コンテンツを出さないための「Trust & Safety（トラスト＆セーフティ）」の仕組みがあります。 詳細はお話しできませんが、さまざまなアルゴリズムでスコアリングを行い、必要に応じて記事を非表示にしたり、人の目で確認したりしています。

もう一つは、「サービス全体の雰囲気づくり」です。 世の中には、議論を呼びそうな強い言葉の投稿をたくさん流すことで盛り上がりをつくる SNS もありますが、 note はあまりそういうトーンが前面に出ないようにしています。 どんなコンテンツを歓迎して、どんなコンテンツは歓迎しないか――アルゴリズム以前に、サービスとしてのスタンスを決めることの方が重要だと考えています。

3-2. 金谷武明さんに聞く「SNSの光と影、その向こう側」

SNSの黎明期からその変化を見続けてきた金谷武明さんに、フィルターバブルやエコーチェンバー、
そして生成AI時代の SNS との付き合い方について伺いました。

聞き手

私たちの生活にとって身近な存在になった SNS ですが、今の各種プラットフォームの課題について、どうお考えですか。

金谷さん

SNS の課題は本当にたくさんありますが、まず「本来の楽しさ」があまり理解されていないと感じています。

もともと Twitter の初期には、「ゆるいコミュニケーションが広がって、豊かな対話が生まれる」といったことが公式サイトにも書かれていて、 僕はそういう部分に共感して使い始めました。 でも今の SNS では、そういったポジティブな側面よりも、戦場のようなやりとりが目立ってしまっているのが残念ですね。

金谷さん

もう一つの課題は、反応の偏りです。 100件ポジティブなリアクションがあっても、1件のネガティブな反応に引きずられてしまう。 不特定多数に向けて発信する場なので、そこで誹謗中傷や断絶が起きると、発言する側はどんどん萎縮していきます。

topic
フィルターバブル――同じ意見ばかりに囲まれる怖さ
聞き手

SNS の課題として、フィルターバブル現象がよく挙げられます。 この点についてはどう見ていますか。

金谷さん

まずは「そういう現象がある」ということを、もっと多くの人が認識する必要があると思います。 リアルな人間関係でも、似た考えの人とばかり付き合っていれば、世界の見え方はどんどん偏っていきますよね。

SNS では、アルゴリズムが「関心がありそうな情報」をどんどん持ってきてくれるので、その傾向がさらに加速します。 自分と似た意見ばかりが流れてくると、「自分は正しい」という確信だけが強くなってしまう。 その一方で、反対意見に触れる機会はどんどん減っていきます。

金谷さん

本来、SNS は自分の視野を広げることもできるツールのはずです。 でも「自分の思想を裏付ける証拠集め」のために使ってしまうと、フィルターバブルはどんどん強まってしまう。 個人的には、そういう使い方があまり好きではないですね。

topic
レコメンドとビジネスモデルのジレンマ
聞き手

レコメンド機能を最適化することが、フィルターバブルやエコーチェンバーを強めてしまうとも言われます。 この点についてはどう感じますか。

金谷さん

基本的には、その通りだと思います。 だからこそ大事なのは「サービスを作っている側の思想や考え方」です。

多くの SNS は広告モデルで成り立っていて、インプレッションが増えれば増えるほど広告が表示され、売上につながる構造になっています。 その中で「できるだけ長く利用してもらいたい」「強い反応が起きる投稿を優先したい」と考えれば、レコメンドはどうしても偏りやすくなる。

一方で、「いろいろな意見を見てほしい」と考えるなら、反対意見をあえて混ぜる設計だってできるはずです。 つまり問題はアルゴリズムの精度そのものではなく、「どんな前提で設計しているか」というビジネスモデルと価値観の方なんですよね。

topic
生成AI時代、それでも「根本はあまり変わらない」かもしれない
聞き手

生成AIや高度なパーソナライズが進んでいく未来を見据えると、フィルターバブルやエコーチェンバーはどう変化していくと考えますか。

金谷さん

サービスの種類によって事情はかなり違うと思います。 X のように思想的な発言が多い場と、Instagram や TikTok のように娯楽色の強い場では、問題の出方も変わります。

ただ、エコーチェンバーやフィルターバブルの問題自体は以前から指摘され続けていて、今後も少しずつ対策が進んでいくとは思いますが、 「劇的に何かが変わる」というよりは、ゆっくりとした変化かもしれません。

その中で大事なのは、ユーザー側の自衛やリテラシー教育だと感じています。 誹謗中傷のように目に見える問題もあれば、「ぼーっと見ているだけで思想が偏っていくかもしれない」という、もっと曖昧で気づきにくい問題もある。

だからこそ、研究者や教育者、今回のように問題提起をする人たちが 「こういう仕組みで、こういうリスクがある」と伝えていくことが重要ですし、 プラットフォーム側も仕組みやルールについて透明性を高めていく必要があると思います。

STEP 3

高校生チームのアフターセッションと、私たちの答え

note・金谷武明さんへのインタビューを終えたあと、私たちは高校生同士であらためて「何を受け取ったのか」「これからどう SNS と付き合っていきたいのか」を話し合いました。
ここでは、そのときのセッションの一部と、そこからまとめた私たちなりの指針を紹介します。

タカクラ

まず、一番びっくりしたのは note さんが「ランキングも広告も置かない」ってはっきり言っていたところかな。 ビジネスとしてはむしろ置いたほうが稼げそうなのに、それでも「空気」を優先しているのが印象的だった。

タナカ

分かる。「クリエイターがストレスを感じない場所にしたい」っていう言葉が、そのまま設計に落ちている感じがしたよね。 アルゴリズムって冷たいものだと思っていたけど、どんな価値観で動かすか次第なんだな、って。

タカクラ

金谷さんの話も、「技術そのものより、どういうビジネスモデルで使われているかのほうが問題だ」っていうのが刺さった。 たしかに、同じレコメンドでも「滞在時間を伸ばすため」なのか、「いろんな意見を見てもらうため」なのかで、まったく違う使い方になるよね。

タナカ

フィルターバブルやエコーチェンバーの話も、「アルゴリズムが悪い」というより、 「自分の気持ちいい世界だけを強化する使い方をしちゃう人間側の問題もある」っていう視点が新鮮だった。

タカクラ

うん。だからこそ、「使う側」としての責任も逃れられないなって。 タイムラインに出てきたものをそのまま世界のすべてだと思わないで、一回立ち止まるクセをつけないといけないのかも。

タナカ

それと同時に、「しんどかったら距離を取っていい」ってことも、もっと言葉にしていいと思った。 可処分時間の奪い合いって話があったけど、私たちがそのゲームから降りる権利も、ちゃんとあるはずだから。

タカクラ

そうだね。完全に SNS をやめるのは現実的じゃないとしても、「ここからここまでは見ない」とか、 「この時間帯はアプリを開かない」とか、自分でルールを決めてもいい。

タナカ

あと、プラットフォーム側に「もっと説明してほしい」と言っていくことも、ユーザーにできることだよね。 アルゴリズムがどう動いているのか、何を重視しているのか。知らないままだと、怖さだけがふくらんじゃうから。

タカクラ

結局、アルゴリズムは「敵」でも「味方」でもなくて、私たちと一緒に社会を形作っている一つの道具なんだと思う。 だからこそ、任せっぱなしにせずに、自分たちの側からも関わり方を選び直していきたいよね。

タナカ

うん。そのうえで、「私たちはこういう未来の SNS を望むし、こう生きたい」というのを、 ちゃんと文章として残しておきたいな。せっかくインタビューまでしたんだし。

それでも、私たちはSNSと生きていく ― アルゴリズム時代をわたるための小さな指針

インタビューを通して見えてきたのは、「アルゴリズム＝悪者」という単純な図では説明できない現実でした。 note のように、あえてランキングや広告を置かず、クリエイターのストレスを減らす方向に使われているアルゴリズムもあれば、 可処分時間をできるだけ多く奪うために最適化されている仕組みもある。 技術そのものよりも、「どんな世界を目指して設計されているか」が決定的に重要だということです。

同時に、フィルターバブルやエコーチェンバーの問題は、「使う側」の選び方とも深く結びついていると分かりました。 自分と同じ意見の投稿ばかりをフォローすれば、タイムラインはどんどん心地よく、そしてどんどん狭くなっていきます。 「世界が偏って見える」ようにしているのは、アルゴリズムだけではなく、自分自身の行動でもあるのかもしれません。

だからこそ、私たちは「つくる側」と「使う側」のあいだに立つ高校生として、次のような小さな指針を持っていたいと考えました。

1. アルゴリズムに「任せっぱなし」にしない

  • タイムラインに流れてくる情報を、「世界のすべて」とは思い込まない。
  • おすすめの理由や仕組みについて、説明を求めたり調べたりする姿勢を忘れない。
  • レコメンドだけでなく、自分から検索したり、本や人との会話など別の経路も持つ。

2. しんどいときは、距離を取る権利がある

  • 「なんとなく疲れた」と感じたら、タイムラインから一度離れてもいいと自分に許可する。
  • 一日のどこかに、完全にオフラインで過ごす時間を少しだけつくってみる。
  • 通知を全部オンにするのではなく、自分が本当に必要だと思うものだけ残す。

3. 一緒にルールをつくる側に回る

  • プラットフォームの利用規約やポリシーに関心を持ち、「何が歓迎されている場なのか」を知る。
  • おかしいと思った仕様や空気に対しては、ユーザーとして声を届けることも選択肢に入れる。
  • 将来、もしサービスをつくる立場になったら、「どんな世界を実現したいか」から設計を始める。

アルゴリズムは、ただの「魔法の黒箱」ではありません。 それを設計する人たちの価値観と、それを使う私たち一人ひとりの選択が混ざり合って、はじめて社会のかたちを変えていきます。 このインタビューとセッションが、あなた自身と SNS との距離を、少しだけ見直してみるきっかけになれば嬉しいです。
